# Everything you can replace

A checklist of the characters, places and names in the game. Fill in the **Your version** column (a name
plus a line or two about them is plenty) and Claude builds it, like Professor Mo.

- 🟢 = names and dialogue only. Cheap: Claude does it all.
- 🎨 = also needs a new look: one Gemini image per character or Pokémon (prompts provided). Until the art
  exists, the character keeps the old sprite with the new name and lines.

Order is roughly the order players meet things, so it's a good order to fill it in.
